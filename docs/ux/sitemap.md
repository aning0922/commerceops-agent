# 页面导航草案

当前实际原型仅包含 POC-S01 任务中心 → POC-S02 库存分析报告 → POC-M01 数据口径弹窗，报告可返回任务中心。两个界面 Board 在同一个 Penpot Page 平铺；组件主实例在另一原生 Page。侧栏中其他名称只展示未来信息架构，未连接的项不算可用导航。

| ID | M1 规划入口与出口 | 边界 |
|---|---|---|
| M1-S01 登录 | 有效服务端会话进入 M1-S02；失败保留表单；过期回登录 | 预置账号，不提前做飞书 OAuth |
| M1-S02 任务中心 | 任务行到报告/轨迹；创建分析到排队状态；待审批到 M1-S04 | 必须校验允许任务范围 |
| M1-S03 报告 | 来源/口径查看；计划到审批；重新分析到新版本轨迹 | 未知库存和不完整数据不可执行 |
| M1-S04 审批 | 冻结计划与全部 SKU；有效决定后看执行中/既有决定 | admin 不继承 approver |
| M1-S05 内部补货管理 | 一个工作项打开完成/关闭原因弹窗 M1-M01 | 无批量、重开、库存或采购修改 |
| M1-S06 轨迹 | 节点、工具/模型用量、审批、业务回执及投影结果；返回原任务 | 不展示秘密或思维链；unknown 先对账 |
| M1-S07 访问限制 | 未登录回登录；已登录无权限说明范围 | 不泄漏其他组织/店铺任务 |
| M1-S08 管理说明 | 最小配置与异常处理说明，受 admin 授权 | 不是组织树/通用 RBAC 平台 |
| M1-F01 飞书审批卡片 | 同一审批合同；相关授权任务/报告可定位 | 画布模拟不替代真实飞书回调验收 |

完整画布、四角色旅程及登录/加载/失败/过期原型尚未制作，详见 [screens.yaml](screens.yaml) 的 `planned_unmapped`。M1-S08 最小配置的具体页面形态需要阶段 C 评审，不由本稿承诺新的配置 API。
