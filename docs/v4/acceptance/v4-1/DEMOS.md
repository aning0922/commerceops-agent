# V4.1 演示流程（DRAFT）

本页用于受控合成数据演示，不是最终浏览器或视觉验收。r8 整案已失败闭合；当前批量、真实移动端和 Native 修复仍待新组合验收，最终截图与视觉核验 pending。历史服务和窗口已关闭；先按 [本地复现说明](../../v4-1/proposals/LOCAL_DEMO_REPRODUCTION.md) 准备并获准启动新的 owned 案，再使用该案实际生成的地址、会话和店铺。不要复用历史 URL、once、身份或资源。

1. **同源经营指标与钻取**：在欢迎页建立演示空间，选择当前访客获授权的店铺；打开经营驾驶舱，记下店铺、币种、时区、期间与来源，切换期间并查看 KPI。点击一个指标的“查看明细”，核对明细与指标的范围、来源和数据版本。未知成本或时间保留未知，不推造毛利。
2. **商品标签与订单模拟履约**：从商品列表打开当前商品，查看 SKU 和来源；在详情中编辑标签、确认后重新读取。打开已记录支付的订单，检查确认覆盖层并执行演示履约，核对回读；支付时间未知的订单应禁用该操作。这些改变是合成演示覆盖层，不写入真实 Woo 商店或物流。
3. **CSV/XLSX 导入与回读**：在商品导入页依次选择仅含合成数据的 CSV 和受支持 XLSX，为每次上传映射 SKU、商品名称、价格和币种，检查预览及质量问题后显式确认。按各自唯一 SKU 在商品列表查询，核对商品来源与导入作业；返回经营驾驶舱，在同一店铺、币种和数据版本下核对商品相关指标。预览不等于确认，结果未知时保留原操作身份并先核对，不自动重发。

14 个导航是范围入口，其中规划类别尚未开放；本期有 12 个业务视图。规则洞察不调用模型，智能助手显示模型未启用。演示流程不等同于真实商店、生产系统或最终验收。逐页截图和操作核对见 [UI 验收清单](../../v4-1/proposals/UI_ACCEPTANCE_CHECKLIST.md)。
